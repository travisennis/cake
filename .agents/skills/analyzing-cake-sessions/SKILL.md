---
name: analyzing-cake-sessions
description: |
  Analyze a persisted cake CLI session file (`~/.local/share/cake/sessions/{uuid}.jsonl`) to find issues and recommend project improvements, optionally also scoring how well cake performed. Use for retrospective analysis of a persisted session, including quality scoring and improvement recommendations. If the user reports that the latest run failed, crashed, hung, or returned incomplete output and wants reactive diagnosis, use `debugging-cake` instead. If the failure is a sandbox denial, use `debugging-sandbox`.
