# Update All Project Dependencies

## Problem

The project's direct and development dependencies in `Cargo.toml` are at specific versions that may be outdated. Running `cargo update` recently showed several transitive dependency updates available, but the direct dependency version constraints have not been audited for newer minor/patch releases. Keeping dependencies current ensures access to bug fixes, security patches, performance improvements, and new features while avoiding accumulation of technical debt from stale version pins.

## Relevant Files

- `Cargo.toml` — the manifest file where all dependency version constraints are declared.

## Fix Direction

1. Install or use `cargo-outdated` (`cargo install cargo-outdated`) to list direct dependencies with newer versions available.
2. Alternatively, use `cargo upgrade --dry-run --workspace` (from `cargo-edit`) to see what `cargo upgrade` would change.
3. For each outdated dependency, review the changelog/semver for breaking changes:
   - **Patch bumps** (e.g., `1.0.102` → `1.0.105`) are safe to apply directly.
   - **Minor bumps** (e.g., `1.0.x` → `1.1.x`) should be reviewed for deprecations or behavior changes in the project's usage surface.
   - **Major bumps** (e.g., `1.x` → `2.x`) require careful review per dependency.
4. Update version constraints in `[dependencies]` and `[dev-dependencies]` sections of `Cargo.toml`.
5. Run `cargo update` to lock the new versions.
6. Run the full test suite (`cargo test --all-features`) and any integration checks to verify nothing is broken.
7. Consider running `cargo audit` to check for known security vulnerabilities in the updated dependency tree.

## Acceptance Notes

- [x] Every direct dependency version constraint in `Cargo.toml` has been reviewed and updated to the latest compatible version.
  - `anyhow`: 1.0.102 → 1.0.103 (patch bump)
  - `chrono`: 0.4.44 → 0.4.45 (patch bump)
  - All other 25 direct/dev dependencies were already at their latest compatible versions.
- [x] `cargo test --all-features` passes cleanly — 957 tests passed, 0 failed.
- [x] `cargo build --release` succeeds.
- [x] No new warnings are introduced by the dependency updates.
- [x] `cargo audit` shows no vulnerabilities.
- [x] No breaking changes — both updates were patch-compatible semver bumps.
