# Support .worktreeinclude

## Summary

Add support for a `.worktreeinclude` file in the project root that automatically copies gitignored files (e.g. `.env`, `.env.local`, `config/secrets.json`) when creating an isolated worktree via the `--worktree` flag.

**Correction (2026-07-07):** there is no `cake worktree` subcommand; worktree isolation is the `--worktree [NAME]` flag on the main command (`src/main.rs`, `setup_worktree`, `src/worktree`). The feature intent is unchanged. This also supports any future fan-out-on-worktrees work, which builds on the same primitive.

## Problem

When using `--worktree`, gitignored files like `.env` and secrets don't exist in the new worktree, so the environment isn't ready. Users have to manually copy these files into every new worktree.

## Relevant Files

- `src/main.rs` — `--worktree` flag and `setup_worktree`
- `src/worktree` module — worktree creation
- Documentation/help text for the `--worktree` flag

## Fix Direction

Introduce a `.worktreeinclude` file in the project root (gitignored-friendly) that lists glob patterns of files to copy into new worktrees. When `--worktree` creates a worktree, read this file and copy matching files from the source tree to the new one. Follow `git worktree add` semantics for where files live.

## Acceptance Notes

- [x] Worktree creation via `--worktree` reads `.worktreeinclude` from the source project root if it exists
- [x] Files matching the glob patterns in `.worktreeinclude` are copied to the new worktree
- [x] Sensible error handling if a listed file doesn't exist in the source
- [x] Document the `.worktreeinclude` format in help text
- [x] Existing worktree tests continue to pass
- [x] Run `cargo fmt` and `just ci` before handoff

## Implementation Summary

Files changed:
- `src/config/worktree.rs` — Added `parse_worktree_includes()`, `copy_worktree_includes()`, `collect_matching_files()`, `glob_match()`, `glob_match_bytes()` functions and 17 new tests. The `create()` function now calls `copy_worktree_includes()` after a successful `git worktree add`.
- `src/main.rs` — Updated `--worktree` help text to mention `.worktreeinclude` support.
- `ci/cargo-crap-baseline.json` — Updated baseline for the new code.

`.worktreeinclude` format:
- One glob pattern per line
- Lines starting with `#` are comments
- Blank lines are ignored
- Glob patterns support `*` (non-separator), `**` (any), and `?` (single char)
- Patterns match against file paths relative to the project root
- `.git` and `.cake` directories are always excluded from traversal
