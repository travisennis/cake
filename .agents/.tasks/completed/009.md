# Add Session Browsing Commands

**Source:** product-ideas.md — Session Browsing

**Triage note (2026-07-07):** unblocked and narrowed. First slice is
`cake sessions list` only (date, first prompt line, UUID for the current
working directory), following the `cake debug models` subcommand pattern.
Full-text search and an interactive picker are follow-on ideas — re-file
them if `list` proves insufficient. Effort reduced M → S for the narrowed
scope. Complements task 222 (replay/export) but shares no code dependency.

**Problem:** You need to know UUIDs to resume sessions; no way to list them.

**Acceptance:**

- `cake sessions list` prints date, first prompt line, and UUID for sessions
  recorded for the current working directory.
- Read-only: no session mutation, no locks.
- Output is stable enough to script against, or a `--json` flag is provided
  (matching `cake debug models --json` precedent).
- `just ci` passes.
