# Replace file:// Absolute URIs in ARCHITECTURE.md

## Problem

ARCHITECTURE.md contains machine-specific absolute URIs like `file:///Users/travisennis/Projects/cake/src/cli/` that break for any other machine or checkout location. They also violate the doc's own convention ("name, don't link" for architecture docs).

Five occurrences exist on lines 30, 41, 83, 99, and 221.

## Relevant Files

- `ARCHITECTURE.md` — the file containing the absolute `file://` URIs in its Codemap section

## Fix Direction

Replace each `file://...` URI with either:
- A plain named path (preferred for codemap entries), e.g. `` `src/cli/` ``
- A repo-relative markdown link where a link is genuinely useful, e.g. `[docs/design-docs/index.md](docs/design-docs/index.md)`

## Acceptance Notes

- [x] `grep -c "file://" ARCHITECTURE.md` returns 0
- [x] Remaining relative links in ARCHITECTURE.md resolve correctly
