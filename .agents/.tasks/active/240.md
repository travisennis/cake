# Generate the System-Prompt Tool List From the Tool Registry

**Created:** 2026-07-07
**Source:** 2026-07-07 backlog triage (bitter-lesson audit V4, prompt-facts portion / Phase 1 item 5).

## Problem

`src/prompts/system.md` hand-codes the available-tools list, including "There is no Glob, Grep, or LS tool" — registry facts maintained by hand in prose. The day the registry changes (toolbox tools per task 121, or any built-in change), the prompt silently lies.

## Fix Direction

- At prompt construction, substitute a generated tool section (names + one-line descriptions) from `ToolRegistry::definitions()` into the built-in prompt; delete the hand-written block from `system.md`.
- Keep the "no Glob/Grep/LS" clarification only if still needed, derived or clearly separated from generated facts.
- Prompt shape is a compatibility surface with snapshot coverage — snapshots are the drift alarm; update them deliberately.
- Coordinate with task 151 (profile prompts) and the future system.md slimming task: generation must apply to the built-in prompt and compose sanely with user overrides (`.cake/system.md` replaces the whole prompt today — document how overrides interact with the generated section).

## Relevant Files

- `src/prompts/mod.rs` — prompt construction
- `src/prompts/system.md` — hand-written block to delete
- `src/clients/tools/mod.rs` — `ToolRegistry::definitions()`
- `src/prompts/snapshots/*.snap`
- `docs/design-docs/prompts.md`
