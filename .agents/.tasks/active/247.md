# Surface .agents/skills to Non-Cake Agents

**Created:** 2026-07-07
**Source:** 2026-07-07 harness assessment (feedback finding #3); maintainer decision 2026-07-07: the repo is worked by many coding agents (cake primary; also claude, codex, acai, amp), so harness knowledge must be agent-agnostic.

## Problem

`.agents/skills/` (analyzing-cake-sessions, debugging-sandbox, debugging-cake, grooming-backlog, preflight, finding-improvements, auditing-binary-size) is discovered only by cake's skill mechanism. AGENTS.md's routing table never mentions the directory, so every other agent working this repo misses playbooks written for exactly the situations it hits (e.g. debugging a Seatbelt denial with the debugging-sandbox skill sitting invisible next door).

## Fix Direction

Cheap, agent-neutral version — no per-agent mirrors:

- Add a short section or route entry in AGENTS.md pointing at `.agents/skills/` as the repo's skill/playbook catalog: what lives there, and when to consult it (sandbox debugging, session analysis, backlog grooming, preflight checks, binary-size audits).
- Keep skills in the agent-neutral location; do not mirror into `.claude/skills/` or other agent-specific directories for now.
- Ensure each skill's SKILL.md has a description line adequate for an agent skimming the directory cold.
- Wording must be agent-agnostic (any agent reading AGENTS.md, not just cake or Claude Code).

## Relevant Files

- `AGENTS.md` — routing/reference addition
- `.agents/skills/*/SKILL.md` — description lines if any are missing or opaque

## Acceptance Notes

- [ ] AGENTS.md tells any agent where repo skills live and when to read them.
- [ ] Each skill has a one-line description discoverable by directory listing plus SKILL.md skim.
- [ ] Wording is agent-agnostic; docs lint passes.
