# Make CI Docs Lint Blocking

## Problem

The CI Docs job runs `panache lint . --quiet || true` (.github/workflows/ci.yml, Docs job). The `|| true` makes the lint advisory-only — it can never fail the build, so doc lint enforcement is decorative.

## Relevant Files

- `.github/workflows/ci.yml` — the Docs job containing `panache lint . --quiet || true`

## Fix Direction

`panache lint . --quiet` currently exits with code 0 (no pre-existing findings), so no cleanup is needed. Simply remove `|| true` from the CI command so `panache lint` becomes blocking.

## Acceptance Notes

- [ ] The CI Docs job runs `panache lint . --quiet` without `|| true`
- [ ] Introducing a deliberate lint violation in a markdown file causes the Docs CI job to fail
- [ ] `panache lint . --quiet` still passes on the current clean tree
