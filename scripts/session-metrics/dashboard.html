Completion means cake ended successfully; it does not measure correctness of the work. Incomplete tasks may be live, crashed, or abandoned. Tool, API, token, and judge metrics use telemetry only. Task outcomes use transcripts and are attributed to task start; other activity uses event timestamps. Missing timestamps fall back to file modification time. Session models describe the session’s saved model; telemetry models describe each invocation.

Cache rate uses only input tokens from requests reporting cached-token details. Edit/Write recovery means a failed call was retried on the same path later in the same session and eventually succeeded; it is attributed to the failed call’s day. Judge time is cumulative attempt time, not an exclusive share of wall time. Retained aggregates contain local project paths and session identifiers; keep this page private. Recent 31 UTC dates are recomputed; older aggregates are retained from earlier refreshes.
