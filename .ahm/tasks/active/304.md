# Convert debugging-cake to a Runbook

**Source:** [.ahm/research/topics/skills-vs-runbooks.md](../../research/topics/skills-vs-runbooks.md); maintainer decisions 2026-07-27. Depends on task 300 for the destination, the ADR amendment, and the stub shape.

## Problem

`.agents/skills/debugging-cake/SKILL.md` is a numbered incident-triage procedure
— locate the failing session, read the records, interpret what each failure
mode means, recover — not a skill that teaches an approach. It belongs in
`docs/runbooks/` where the agent-loop and session routes can name it.

## Scope

1. Move the procedure to `docs/runbooks/debugging-cake.md`.
2. Preserve the triage/analysis boundary the current skill establishes. Its
   description deliberately routes deep session review to
   `analyzing-cake-sessions` and sandbox denials to `debugging-sandbox`; those
   cross-references must keep working after both targets become runbooks. Land
   this after or alongside the sibling conversions so the links do not dangle.
3. Reduce `.agents/skills/debugging-cake/SKILL.md` to the pointer stub shape
   established by task 300 — frontmatter with the existing `name` and multi-line
   `description` preserved verbatim, plus a pointer at the runbook. Do not
   delete the skill.
4. Add the runbook to the relevant `AGENTS.md` routes and cross-link from
   [docs/integrations.md](../../../docs/integrations.md), which owns exit codes
   and session layout — the two things triage reads first.

Preserve the existing `description` text exactly, including its routing bullets.
It is what drives retrieval and what keeps the three procedures from being
invoked for each other's cases.

## Relevant Files

- `.agents/skills/debugging-cake/SKILL.md` — source procedure
- `docs/runbooks/debugging-cake.md` — destination
- `docs/integrations.md` — exit codes, persisted-session layout, record semantics
- `docs/adr/011-interrupt-handling.md` — interrupt and shutdown behavior the
  runbook should reference rather than restate
- `AGENTS.md` — workflow routes

## Guardrail

Behavior-shaping change under
[docs/guardrails/agent-instructions.md](../../../docs/guardrails/agent-instructions.md).

- **Observed failure:** the procedure is reachable only through cake's skill
  catalog. Completed [task 247](../completed/247.md) recorded that agents other
  than cake miss `.agents/skills/` entirely, which is why the `.claude/skills`
  symlink exists.
- **Expected observable change:** an agent handed a failed cake run reaches the
  triage runbook through `AGENTS.md` routing, and still routes deep review and
  sandbox denials to the correct sibling procedure.
- **Verification:** fresh-session probe — give a new agent session a truncated
  or errored cake run to triage and check whether it retrieved the runbook and
  respected the triage/analysis split. If the probe is not run, record that
  verification is deferred and that this is the probe that would establish it.
