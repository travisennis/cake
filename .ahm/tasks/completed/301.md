# Convert auditing-binary-size to a Runbook

**Source:** [.ahm/research/topics/skills-vs-runbooks.md](../../research/topics/skills-vs-runbooks.md); maintainer decisions 2026-07-27. Depends on task 300 for the destination, the ADR amendment, and the stub shape.

## Problem

`.agents/skills/auditing-binary-size/SKILL.md` is explicit prerequisites plus
numbered commands for a repeatable audit. It teaches nothing; it is a procedure.
It is also the smallest and least entangled of the four conversions, which makes
it the right one to land first and use as the shape check for the rest.

## Scope

1. Move the procedure to `docs/runbooks/auditing-binary-size.md`.
2. Reduce `.agents/skills/auditing-binary-size/SKILL.md` to the pointer stub
   shape established by task 300 — frontmatter with the existing `name` and
   `description` preserved verbatim, plus a pointer at the runbook. Do not
   delete the skill.
3. Route it from the build and verification section of
   [AGENTS.md](../../../AGENTS.md), and cross-link from
   [CONTRIBUTING.md](../../../CONTRIBUTING.md), which is the canonical command
   catalog. The runbook's `cargo-bloat` prerequisite is a command-catalog fact
   and should not silently diverge from it.
4. Verify the commands in the procedure still work before moving them. A
   procedure nobody has run in a while is a plausible source of stale flags.

Preserve the existing `description` text exactly. It is what drives retrieval.

## Relevant Files

- `.agents/skills/auditing-binary-size/SKILL.md` — source procedure
- `docs/runbooks/auditing-binary-size.md` — destination
- `CONTRIBUTING.md` — canonical command catalog and verification policy
- `justfile` — existing build recipes the runbook should reuse rather than
  restate
- `AGENTS.md` — build and verification route

## Guardrail

Behavior-shaping change under
[docs/guardrails/agent-instructions.md](../../../docs/guardrails/agent-instructions.md).

- **Observed failure:** the procedure is reachable only through cake's skill
  catalog. Completed [task 247](../completed/247.md) recorded non-cake agents
  missing `.agents/skills/` entirely.
- **Expected observable change:** an agent asked to investigate binary size
  reaches the runbook through the build route rather than through skill
  discovery.
- **Verification:** fresh-session probe — ask a new agent session to audit
  binary size and check whether it retrieved the runbook. As the first of the
  four conversions, this probe is also the cheapest test of whether
  `AGENTS.md` routing works at all; a failure here is a signal to revisit the
  routing design before converting the remaining three.
- If the probe is not run, record that verification is deferred and that this is
  the probe that would establish it.
