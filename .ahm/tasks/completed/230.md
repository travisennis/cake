# Deduplicate Docs Index Tables

## Problem

The guardrails table is hand-maintained in two places — `docs/README.md` and `docs/guardrails/index.md` — with already-divergent "Use for" descriptions. The design-docs table is likewise duplicated between `docs/README.md` and `docs/design-docs/index.md`. Every new doc requires edits in multiple places, and the copies are drifting.

## Relevant Files

- `docs/README.md` — has Guardrails table (9 rows) and Design docs table (13 rows)
- `docs/guardrails/index.md` — has same Guardrails table (9 rows) with different "Use For" phrasing
- `docs/design-docs/index.md` — has similar Design docs table (14 rows including ADR link)

## Fix Direction

Keep the per-directory `index.md` files (`docs/guardrails/index.md`, `docs/design-docs/index.md`) as the detailed authoritative tables. Reduce `docs/README.md` to one-line links pointing to those indexes. No `AGENTS.md`/guardrail references point at the tables directly, so no reference updates are needed.

## Acceptance Notes

- [x] Each doc set (guardrails, design-docs) is enumerated in exactly one file
- [x] The other location (docs/README.md) links to the authoritative index rather than duplicating the table
- [x] No broken links are introduced
