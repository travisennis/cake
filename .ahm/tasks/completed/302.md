# Convert debugging-sandbox to a Runbook

**Source:** [.ahm/research/topics/skills-vs-runbooks.md](../../research/topics/skills-vs-runbooks.md); maintainer decisions 2026-07-27. Depends on task 300 for the destination, the ADR amendment, and the stub shape.

## Problem

`.agents/skills/debugging-sandbox/SKILL.md` is a repeatable operational
procedure — quick diagnosis, denial tracing, profile repair, verification — not
a skill that teaches an approach. It belongs in `docs/runbooks/` where the
sandbox workflow route can name it directly.

It has a second defect the move should fix. The skill is written almost entirely
around macOS Seatbelt (`sandbox-exec`, `.sb` profiles, `$TMPDIR/cake/sandbox_profiles/`)
while cake also sandboxes on Linux via Landlock. An agent hitting a Landlock
denial gets macOS instructions.

## Scope

1. Move the procedure to `docs/runbooks/debugging-sandbox.md`.
2. Branch the diagnosis explicitly between macOS Seatbelt and Linux Landlock.
   Landlock denials do not produce Seatbelt-style profile traces, so the two
   paths need different reproduction and different repair steps. Read
   `src/` for the actual Landlock enforcement behavior rather than inferring it;
   [ARCHITECTURE.md](../../../ARCHITECTURE.md) names the code authority.
3. Reduce `.agents/skills/debugging-sandbox/SKILL.md` to the pointer stub shape
   established by task 300 — frontmatter with the existing `name` and
   `description` preserved verbatim, plus a pointer at the runbook. Do not
   delete the skill.
4. Add the runbook to the sandbox route in [AGENTS.md](../../../AGENTS.md) and
   cross-link from [docs/security.md](../../../docs/security.md).

Preserve the existing `description` text exactly. It is what drives retrieval,
and rewording it changes discovery behavior independently of this move.

## Relevant Files

## Guardrail

Behavior-shaping change under
[docs/guardrails/agent-instructions.md](../../../docs/guardrails/agent-instructions.md).

- **Observed failure:** the procedure is reachable only through cake's skill
  catalog, and it silently assumes macOS. Completed
  [task 247](../completed/247.md) recorded non-cake agents missing this exact
  skill ("debugging a Seatbelt denial with the debugging-sandbox skill sitting
  invisible next door").
- **Expected observable change:** an agent triaging an `Operation not permitted`
  failure reaches the runbook through the sandbox route, and on Linux follows
  Landlock steps rather than `sandbox-exec` steps.
- **Verification:** fresh-session probe — give a new agent session a sandbox
  denial to triage and check whether it retrieved the runbook and used the
  correct platform branch. If the probe is not run, record that verification is
  deferred and that this is the probe that would establish it.
