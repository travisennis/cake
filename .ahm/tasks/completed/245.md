# Warn When a Configured Skills Path or Profile Yields Zero Skills

**Created:** 2026-07-07
**Source:** 2026-07-07 harness assessment (feedback finding #1): every cake profile pointed at a skills directory that no longer exists, and profile `only` lists named archived or nonexistent skills — silently. A system premised on measured feedback had a whole limb failing with no signal.

## Problem

When `skills.path` points at a missing/empty directory, or a profile's `only` list names skills that don't resolve, cake proceeds silently with zero (or fewer) skills. Nothing in diagnostics, stderr, or the metrics pipeline reveals the rot.

## Fix Direction

- At skill discovery: if a configured skills path does not exist or resolves to zero skills, emit a concise stderr warning naming the path and its source (which settings file / profile).
- If a profile `only`/filter list names skills that were not discovered, warn with the missing names.
- Keep it one line per problem, warning not error — the run proceeds.
- Consider a `cake debug skills` subcommand (following `cake debug models`) listing resolved skills and their sources; optional scope, decide during implementation.
- Record the condition in the telemetry sidecar so the metrics suite can see configuration rot across sessions.

## Relevant Files

- `src/config/skills.rs` — discovery
- `src/config/settings.rs` — profile/skills path resolution
- `src/cli/debug.rs` — if `cake debug skills` is included
- `src/session_telemetry.rs` — optional rot signal
- Docs for settings/skills

  - Existing-but-empty configured path: new warning diagnostic added with message including the path.
- [x] Unresolvable `only`-list entries → warning naming the missing skills.
  - `SkillConfig::apply` now checks each requested name against discovered skills and emits a `Warning` diagnostic for each missing name.
- [x] Healthy configurations produce no new output.
  - `discover_skills_with_paths_non_empty_dir_does_not_emit_empty_warning` and `skill_config_apply_only_all_found_no_diagnostics` tests verify this.
- [x] Tests cover missing path, empty path, and only-list miss.
  - 5 new tests added to `src/config/skills_tests.rs`.

  - All 837 unit tests + all integration tests pass; `cargo fmt --check` OK; `cargo clippy --all-targets` clean.
