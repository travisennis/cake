Edit text in files using literal search-and-replace. All non-no-op edits in a single call succeed atomically or none are applied. Edits with identical old_text and new_text are skipped.

The configured `read_max_output_bytes` limit also caps the input file size Edit will read (100,000 bytes by default); `"unlimited"` disables that cap.

Guidance:
- Always Read the file first before editing.
- old_text must match exactly once in the file. Include 3+ surrounding lines for uniqueness.
- For multi-line matches, preserve exact whitespace and indentation.
- Special characters in JSON (backticks, quotes, backslashes) must be escaped.
- Each successful edit invalidates any earlier read of that file. Re-read before editing the same file again.
- The parameters are named old_text and new_text (not old_string/new_string).
