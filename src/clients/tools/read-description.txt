Read a text file as unnumbered lines, optionally a line range. Defaults to the configured window from `start_line` (500 lines by default). Use Read instead of cat.

The `File:` and `Lines X-Y/Z` lines are metadata, not file content.
Do not include them in Edit text.
A truncated result names the next `start_line` to read. Ranged and truncated reads return only that region; use exact returned lines for later edits.
Rejects binary files and directories.
