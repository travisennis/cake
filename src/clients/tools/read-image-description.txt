View an image file (PNG, JPEG, GIF, WebP) and return it as an image you can see.
Use ReadImage when a screenshot, diagram, chart, or photo is part of the question.
Read rejects binary files.
The path must be inside the sandbox's read grants; credential-bearing paths stay denied.
Large images may be downscaled to fit the request budget; the source file is unchanged.
Prefer the smallest image that answers the question.
