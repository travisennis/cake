Read a bounded range, byte window, or literal-search result from a tool result that was replaced by an externalized summary. Use this when a Bash, MCP, or toolbox result of at least 16 KiB shows a retrieval handle instead of its full text.

Pass the handle from the summary. Return a 1-indexed inclusive line range with `start_line` and `end_line`, or pass `search` to find literal, case-sensitive text and include limited context. Set `context_lines` from 0 to 5; it defaults to 2.

When a single line is longer than one result, the footer names the next 0-based byte offset. Continue with `start_byte` and an optional exclusive `end_byte`; do not combine a byte window with a line range or search. A search over a long line excerpts the text around the match instead of returning only the line start.

This tool reads only the current session's retained output. It never accepts a filesystem path, blob digest, or session id, and it rejects unknown or cross-session handles. Its result is bounded; when it truncates, the footer names the line or byte offset to request next.
