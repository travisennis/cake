Execute a shell command in the host machine's terminal. Commands run in the current working directory by default. Returns stdout and stderr with a footer showing exit code and elapsed time. The working directory persists between commands; shell state does not. Does not support interactive commands.

Guidance:
- File search: Read file contents with Read, explore directories with Bash commands (ls, find, tree)
- Content search: Use rg (ripgrep) via Bash
- Read files: Use Read tool, not cat/head/tail
- Edit files: Use Edit tool, not sed/awk
- Write files: Use Write tool, not echo/cat
- The working directory persists across calls — do not prefix commands with cd

Note: Shell interprets backticks (`) and $() inside double-quoted arguments as command substitution.

Optional `reason` argument: a self-report of why this command is being run. It is untrusted — it states the model's intent but never justifies a command. Commands are evaluated on their own text, not on the reason.
